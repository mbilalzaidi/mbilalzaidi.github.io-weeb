1. Introduction

This comprehensive guide will walk you through setting up a complete production environment on a Hostinger KVM VPS. By the end of this tutorial, you'll have:

  • A secure VPS running Ubuntu
  • Ollama AI service running on port 11434
  • Nginx as a reverse proxy
  • SSL certificates for secure HTTPS connections
  • Your domain (learnwithus.cloud) properly configured
  • A Flutter app connected to your backend

2. Prerequisites

Before you begin, make sure you have:
  • A Hostinger KVM 4 VPS subscription
  • Domain name: learnwithus.cloud
  • SSH client (Terminal on Mac/Linux, PuTTY on Windows)
  • Basic command line knowledge
  • Flutter development environment set up locally

3. Initial VPS Setup

Step 3.1: Access Your VPS

After purchasing your Hostinger KVM VPS, you'll receive:

  • IP address (e.g., 192.168.1.100)
  • Root username and password

Connect to your VPS via SSH:

ssh root@your-server-ip
⚠️ Note: Replace your-server-ip with your actual VPS IP address.

Step 3.2: Update Your System

First, update all packages to their latest versions:

apt update && apt upgrade -y

This may take a few minutes depending on your connection speed.

Step 3.3: Create a Non-Root User

For security reasons, create a new user instead of using root:

# Create new user
adduser webadmin

# Add user to sudo group
usermod -aG sudo webadmin

# Switch to new user
su - webadmin

4. Security Configuration

Step 4.1: Configure Firewall (UFW)

Set up UFW (Uncomplicated Firewall) to protect your server:

# Install UFW
sudo apt install ufw -y

# Allow SSH (important: do this first!)
sudo ufw allow 22/tcp

# Allow HTTP and HTTPS
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp

# Note: Don't expose Ollama port directly
# Access it through Nginx reverse proxy instead

# Enable firewall
sudo ufw enable

# Check status
sudo ufw status
⚠️ Critical: Always allow SSH (port 22) before enabling the firewall, or you'll lock yourself out!

Step 4.2: Configure SSH Key Authentication

On your local machine, generate an SSH key pair:

# On your local machine
ssh-keygen -t rsa -b 4096 -C "your_email@example.com"

# Copy public key to server
ssh-copy-id webadmin@your-server-ip

Now you can login without a password!

5. Installing Ollama

Step 5.1: Install Ollama

Ollama is an easy-to-use tool for running large language models locally. Install it with:

# Install Ollama
curl -fsSL https://ollama.com/install.sh | sh

# Verify installation
ollama --version

Step 5.2: Configure Ollama as a System Service

Create a systemd service file to run Ollama automatically:

sudo nano /etc/systemd/system/ollama.service

Add the following content:

[Unit]
Description=Ollama Service
After=network.target

[Service]
Type=simple
User=webadmin
Environment="OLLAMA_HOST=0.0.0.0:11434"
ExecStart=/usr/local/bin/ollama serve
Restart=always
RestartSec=3

[Install]
WantedBy=multi-user.target

Enable and start the service:

sudo systemctl daemon-reload
sudo systemctl enable ollama
sudo systemctl start ollama
sudo systemctl status ollama

Step 5.3: Pull a Model

Download a language model (we'll use llama2 as an example):

# Pull llama2 model
ollama pull llama2

# Test it
ollama run llama2 "Hello, how are you?"
💡 Tip: You can also try other models like mistral, codellama, or phi. Use ollama list to see installed models.

Step 5.4: Test Ollama API

Verify that Ollama is accessible on port 11434:

# Test locally
curl http://localhost:11434/api/generate -d '{
  "model": "llama2",
  "prompt": "Why is the sky blue?",
  "stream": false
}'

6. Installing & Configuring Nginx

Step 6.1: Install Nginx

# Install Nginx
sudo apt install nginx -y

# Start and enable Nginx
sudo systemctl start nginx
sudo systemctl enable nginx

# Check status
sudo systemctl status nginx

Step 6.2: Configure Nginx for Ollama

Create a new Nginx configuration for your domain:

sudo nano /etc/nginx/sites-available/learnwithus.cloud

Add the following configuration:

server {
    listen 80;
    server_name learnwithus.cloud www.learnwithus.cloud;

    # Redirect to HTTPS (will be enabled after SSL setup)
    # return 301 https://$server_name$request_uri;

    location / {
        root /var/www/html;
        index index.html;
    }

    # Ollama API endpoint
    location /api/ {
        proxy_pass http://localhost:11434/api/;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        
        # Increase timeouts for long-running AI requests
        proxy_read_timeout 300;
        proxy_connect_timeout 300;
        proxy_send_timeout 300;
    }
}

Step 6.3: Enable the Site

# Create symbolic link
sudo ln -s /etc/nginx/sites-available/learnwithus.cloud /etc/nginx/sites-enabled/

# Remove default site
sudo rm /etc/nginx/sites-enabled/default

# Test configuration
sudo nginx -t

# Reload Nginx
sudo systemctl reload nginx

7. SSL Certificate Setup

Step 7.1: Install Certbot

Certbot is a tool for obtaining free SSL certificates from Let's Encrypt:

# Install Certbot
sudo apt install certbot python3-certbot-nginx -y

Step 7.2: Obtain SSL Certificate

⚠️ Important: Before running this command, make sure your domain DNS is pointing to your VPS IP address! 
# Get certificate
sudo certbot --nginx -d learnwithus.cloud -d www.learnwithus.cloud

# Follow the prompts:
# - Enter your email address
# - Agree to terms of service
# - Choose whether to redirect HTTP to HTTPS (recommended: yes)

Step 7.3: Auto-Renewal Setup

Certbot automatically sets up renewal. Test it with:

# Test renewal
sudo certbot renew --dry-run

# Check renewal timer
sudo systemctl status certbot.timer
✅ Success! Your SSL certificate will automatically renew before expiration.

Step 7.4: Update Nginx Configuration for HTTPS

After Certbot, your Nginx config will be automatically updated. Verify the changes:

sudo nano /etc/nginx/sites-available/learnwithus.cloud

You should see SSL configuration added by Certbot. Make sure the Ollama proxy configuration is still present.

8. Domain Configuration

Step 8.1: Configure DNS Records

In your domain registrar's control panel (where you registered learnwithus.cloud), add these DNS records:

Type: A
Name: @
Value: [Your VPS IP Address]
TTL: 3600

Type: A
Name: www
Value: [Your VPS IP Address]
TTL: 3600

Type: CNAME
Name: api
Value: learnwithus.cloud
TTL: 3600
💡 Note: DNS propagation can take 24-48 hours, but usually happens within a few minutes to an hour.

Step 8.2: Verify Domain Resolution

Check if your domain is resolving correctly:

# Check DNS resolution
nslookup learnwithus.cloud

# Test with ping
ping learnwithus.cloud

# Test HTTP access
curl http://learnwithus.cloud

9. Flutter App Integration

Step 9.1: Create Flutter HTTP Client

In your Flutter project, add the http package to pubspec.yaml:

dependencies:
  flutter:
    sdk: flutter
  http: ^1.1.0

Run:

flutter pub get

Step 9.2: Create Ollama Service Class

Create a new file lib/services/ollama_service.dart:

import 'dart:convert';
import 'package:http/http.dart' as http;

class OllamaService {
  final String baseUrl = 'https://learnwithus.cloud/api';
  
  Future<String> generateResponse(String prompt, String model) async {
    try {
      final response = await http.post(
        Uri.parse('$baseUrl/generate'),
        headers: {
          'Content-Type': 'application/json',
        },
        body: jsonEncode({
          'model': model,
          'prompt': prompt,
          'stream': false,
        }),
      ).timeout(const Duration(seconds: 120));

      if (response.statusCode == 200) {
        final data = jsonDecode(response.body);
        return data['response'] ?? 'No response';
      } else {
        throw Exception('Failed to generate response: ${response.statusCode}');
      }
    } catch (e) {
      throw Exception('Error connecting to Ollama: $e');
    }
  }

  Future<List<String>> listModels() async {
    try {
      final response = await http.get(
        Uri.parse('$baseUrl/tags'),
      );

      if (response.statusCode == 200) {
        final data = jsonDecode(response.body);
        return (data['models'] as List)
            .map((model) => model['name'] as String)
            .toList();
      } else {
        throw Exception('Failed to list models');
      }
    } catch (e) {
      throw Exception('Error listing models: $e');
    }
  }
}

Step 9.3: Example Flutter UI Integration

Create a simple chat interface lib/screens/chat_screen.dart:

import 'package:flutter/material.dart';
import '../services/ollama_service.dart';

class ChatScreen extends StatefulWidget {
  const ChatScreen({Key? key}) : super(key: key);

  @override
  State<ChatScreen> createState() => _ChatScreenState();
}

class _ChatScreenState extends State<ChatScreen> {
  final TextEditingController _controller = TextEditingController();
  final OllamaService _ollamaService = OllamaService();
  final List<Map<String, String>> _messages = [];
  bool _isLoading = false;

  void _sendMessage() async {
    if (_controller.text.trim().isEmpty) return;

    final userMessage = _controller.text.trim();
    setState(() {
      _messages.add({'role': 'user', 'content': userMessage});
      _isLoading = true;
    });
    _controller.clear();

    try {
      final response = await _ollamaService.generateResponse(
        userMessage,
        'llama2', // or any model you have installed
      );
      
      setState(() {
        _messages.add({'role': 'assistant', 'content': response});
        _isLoading = false;
      });
    } catch (e) {
      setState(() {
        _messages.add({
          'role': 'error',
          'content': 'Error: ${e.toString()}'
        });
        _isLoading = false;
      });
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Ollama Chat'),
        backgroundColor: Colors.deepPurple,
      ),
      body: Column(
        children: [
          Expanded(
            child: ListView.builder(
              itemCount: _messages.length,
              itemBuilder: (context, index) {
                final message = _messages[index];
                final isUser = message['role'] == 'user';
                
                return Align(
                  alignment: isUser ? Alignment.centerRight : Alignment.centerLeft,
                  child: Container(
                    margin: const EdgeInsets.all(8),
                    padding: const EdgeInsets.all(12),
                    decoration: BoxDecoration(
                      color: isUser ? Colors.blue[100] : Colors.grey[200],
                      borderRadius: BorderRadius.circular(12),
                    ),
                    child: Text(message['content'] ?? ''),
                  ),
                );
              },
            ),
          ),
          if (_isLoading)
            const Padding(
              padding: EdgeInsets.all(8.0),
              child: CircularProgressIndicator(),
            ),
          Padding(
            padding: const EdgeInsets.all(8.0),
            child: Row(
              children: [
                Expanded(
                  child: TextField(
                    controller: _controller,
                    decoration: const InputDecoration(
                      hintText: 'Type a message...',
                      border: OutlineInputBorder(),
                    ),
                    onSubmitted: (_) => _sendMessage(),
                  ),
                ),
                const SizedBox(width: 8),
                IconButton(
                  icon: const Icon(Icons.send),
                  onPressed: _sendMessage,
                ),
              ],
            ),
          ),
        ],
      ),
    );
  }
}

10. Troubleshooting

Common Issue 1: Cannot Connect to VPS

Problem: SSH connection refused or times out

Solutions:

  • Verify IP address is correct
  • Check if VPS is running in Hostinger panel
  • Ensure port 22 is open in firewall
  • Try using VNC console from Hostinger panel
# Check SSH service
sudo systemctl status ssh

# Restart SSH if needed
sudo systemctl restart ssh

Common Issue 2: Ollama Not Responding

Problem: Ollama service not accessible

Solutions:

# Check Ollama status
sudo systemctl status ollama

# View logs
sudo journalctl -u ollama -f

# Restart Ollama
sudo systemctl restart ollama

# Test locally
curl http://localhost:11434/api/tags

Common Issue 3: Nginx 502 Bad Gateway

Problem: Getting 502 error when accessing the site

Solutions:

# Check Nginx error logs
sudo tail -f /var/log/nginx/error.log

# Test Nginx configuration
sudo nginx -t

# Verify Ollama is running
curl http://localhost:11434/api/tags

# Check if ports are listening
sudo netstat -tulpn | grep -E '(80|443|11434)'

Common Issue 4: SSL Certificate Problems

Problem: HTTPS not working or certificate errors

Solutions:

# Check certificate status
sudo certbot certificates

# Renew certificate manually
sudo certbot renew

# Test certificate
openssl s_client -connect learnwithus.cloud:443 -servername learnwithus.cloud

Common Issue 5: DNS Not Resolving

Problem: Domain doesn't point to your server

Solutions:

# Check DNS resolution
nslookup learnwithus.cloud

# Check from different DNS server
nslookup learnwithus.cloud 8.8.8.8

# Clear local DNS cache (on your local machine)
# Mac/Linux:
sudo dscacheutil -flushcache

# Windows:
ipconfig /flushdns

Wait 24-48 hours for DNS propagation if you just updated the records.

Common Issue 6: Flutter App Connection Errors

Problem: Flutter app can't connect to backend

Solutions:

  • Verify HTTPS is working in browser first
  • Check if using correct URL (https://learnwithus.cloud/api)
  • For Android: Add internet permission in AndroidManifest.xml
  • For iOS: Configure App Transport Security if needed
  • Add error handling and logging to see exact error

Android permission (android/app/src/main/AndroidManifest.xml):

<uses-permission android:name="android.permission.INTERNET"/>
